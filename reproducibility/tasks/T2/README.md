# T2 Product and bystander distribution

`inputs/` contains target, outcome and position profiles, the source-file identifiers and the exact adapter panels. `predictions/` contains the returned outcomes and positions by model. `code/score_t2_expanded.py` recomputes the product and position summaries. For matched and random-window comparisons use `common` and `random`.
